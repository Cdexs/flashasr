## 本机终端不绑设备（Gavin 报「点了使用本机，按热键提示要重新配对」，原因 + 方案经 Gavin 同意）

- 原因：本机终端按「首次连接的设备」绑定；当天测试用 Python 参考客户端拿本机 key 连过，本机终端绑到了 `python-ref-client`，输入法再连 ⇒ DeviceMismatch ⇒ 输入法提示「需要重新配对」。
- 修：`pairing::authorize` 本机终端（`local`）不绑设备，只记最近一次连接的设备代码；远程终端照旧绑定。新增单测 `local_terminal_not_device_locked`。
- 验证（主控亲自）：重编重启本机实例，用输入法的设备代码 + 真实录音连本机终端，识别正常出字；终端表记录已更新为输入法的设备代码。
