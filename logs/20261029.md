## FLASH-P2a 服务能力（P2-01 / 02 / 04 / 05 / 06 / 07）

- P2-01 进程结构：`src/front/`（前台 `flashasr`：main / ws / core_link / status / local_pair）、`src/engine/`（引擎 `flashasr-engine`）。前台 `CoreLink` 看护线程拉起引擎、读 `FLASHASR_ENDPOINT` 后开管道（10 秒重试，修启动竞态 os error 2）；引擎状态行 `FLASHASR_STATUS {json}`。实测：杀引擎 5 秒重拉、进行中会话 70ms 收到 `EngineRestarted`；前台退出引擎自退；第二个前台进程被锁拒绝。
- P2-02：`AsrModel` 只剩 `LocalRealtime`，删在线分支与测试；新增「只剩本地实时」测试。
- P2-04：`status.rs`（`read_head` + `Rewind` 倒回给 WebSocket）；无 key 401、杀引擎后报离线。
- P2-05：`frame.rs`（`ScenePayload`、终稿三字段、`EndPayload.speech_ms`、`Kind::ResetVoiceprint`）、`text_stage.rs`（`apply_final_with` + `FinalExtras`，`llm_optimize` 返回没做成的原因，场景进输出优化与大模型翻译）、`scene::kind_from_str`、`session.rs`（`wordbook_hits`、`speech_ms`）、`ws.rs`（`answer_api`、结果 JSON 扩展）。
- P2-06：`pairing::Terminal.local` + `create_local`（不过期）、`local_from_loopback`（非回环 ⇒ InvalidKey）、`local_pair.rs`。实测重启后 key 不变、局域网地址用本机 key 被拒。
- P2-07：协议文档、README 同步；全量测试前台 52 / 引擎 1540 通过，fmt 干净。
- 跨平台：本轮都是平台无关逻辑；macOS 差异只有配对文件位置（`~/Library/Application Support/flashasr/`，0600）和引擎管道实现（沿用 voice-ime 的 Unix 套接字分支，未在 macOS 编译验证，本期不出 macOS 包）。
