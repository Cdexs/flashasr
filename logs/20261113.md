# 2026-11-13 改动日志

## 1. 6位配对码（pair_code）与用户维度（user_id）词库/声纹共享

- **背景与目标**：
  1. 配对时除二维码/连接码外，新增 6 位数字配对码（`pair_code`），前端在配对校验及首次连接时必须同时核验连接码与 6 位配对码。
  2. 新增用户维度 `user_id`（长度不超过 12 位，仅限 ASCII 字母与数字且首字符必须为字母：`^[A-Za-z][A-Za-z0-9]{0,11}$`，大小写敏感），客户端请求需随 `device_id`（主板+CPU 序列号，最长 32 位）与 `device_name` 一并传入 `user_id`。
  3. 服务端按 `user_id` 持久化 `user_words` 与系统自动学习词表 `system_words`，通过 WebSocket 协议扩展 `pair-terminal`、`get-wordbook`、`update-wordbook` 动作（禁止客户端覆盖修改系统词表）；并将声纹槽位挂载到 `user_id`，使同一用户在电脑与手机等不同终端间共享词库与声纹。
  4. 管理端 `flashasr-ui` 在新增终端弹窗展示 6 位配对码，在终端列表中展示所属 `user_id` 与 `device_id`；同步更新 `docs/API.md`、`docs/ASR-PROTOCOL.md` 与 `tools/asr-client/feiyin_asr_client.py`。

- **核心修改**：
  - `src/asr_shared/pairing.rs`、`src/asr_shared/control.rs`、`src/asr_shared/mod.rs`：
    - `Terminal` 新增 `pin_hash`（6 位配对码 SHA-256 哈希）与 `user_id`；新增 `is_valid_user_id`、`is_valid_device_id`、`normalize_pair_code`、`create_with_pin`、`authorize_full`、`any_active_with_vp_key`。
    - `terminal_voiceprint_path` 支持大小写安全文件名编码（含大写字母时附加 `_u<hex_bitmask>`），新增 `user_voiceprint_path`；`Added` 控制消息返回 `pair_code`，`TerminalRow` 返回 `user_id` 与 `device_id`。
  - `src/wordbook/db.rs`、`src/wordbook/mod.rs`：
    - `wordbook` 与 `wordbook_candidates` 增加 `user_id` 列及复合唯一索引 `idx_wordbook_user_word(user_id, word)` / 主键 `(user_id, word)`，提供 `ensure_user_id_schema` 自动迁移旧库。
    - 新增 `get_user_wordbook`、`replace_user_words`、`load_user_words_ordered`、`record_hits_for_user`、`insert_entry_for_user`、`upsert_candidate_for_user`、`delete_candidate_for_user`、`learn_suggestions_for_user`。
    - 同步更新 `setup()` 与 `assert_word_schema()` 测试辅助函数及断言以匹配 `user_id` 新 schema。
  - `src/front/ws.rs`、`src/front/main.rs`：
    - `extract_identity` 解析并校验 `user_id` / `device_id` / `device_name` / `pair_code`，并在单连接内缓存已认证上下文；新增 `InvalidPairCode`、`InvalidUserId`、`UserMismatch` 错误码。
    - 新增 WebSocket 动作 `pair-terminal`（返回 `terminal-paired`）、`get-wordbook`（返回 `wordbook-result`）、`update-wordbook`（返回 `wordbook-updated`，仅替换 `user` 词表）。
    - 终端列表展示 `user_id`/`device_id` 与用户级声纹状态；吊销终端时仅当该声纹 key 不再有其他活跃终端才清理声纹文件；CLI `--add-terminal` 输出 `PAIR_CODE`。
  - `src/asr_service/{frame.rs,mod.rs,session.rs,text_stage.rs}`、`src/llm/mod.rs`：
    - `OpenParams` 携带 `user_id`，引擎 `open_session` 将声纹槽位挂载到 `user_id`（无 `user_id` 时回退终端 ID）。
    - 识别终稿合并 `user_id` 对应词表（`merge_user_vocabulary`）送入 LLM 优化/翻译，并在后台线程中按 `user_id` 异步统计词表命中与学习候选词晋升。
  - `src-tauri/src/server.rs`、`ui/src/{api.ts,pages/Terminals.tsx,i18n/*}`：
    - 透传并在前端三语界面展示 6 位配对码、所属 `user_id` 与 `device_id`，调整吊销/重置声纹提示逻辑。
  - `docs/API.md`、`docs/ASR-PROTOCOL.md`、`tools/asr-client/{feiyin_asr_client.py,test_feiyin_asr_client.py}`：
    - 补全配对码、用户 ID、新 WebSocket 动作及错误码说明；参考客户端新增 `--user-id`（默认 `user01`）、`--pair-code`、`--get-wordbook`、`--update-wordbook`。

- **跨平台影响评估**：
  - **Windows**：NTFS 路径大小写不敏感，已通过 `terminal_voiceprint_path` 的 `_u<bitmask>` 编码保证 `Gavin01` 与 `gavin01` 等大小写不同 `user_id` 的声纹文件隔离；未引入新 Windows API。
  - **macOS**：APFS 默认同样大小写不敏感，该大小写安全文件名规则及 SQLite 迁移/WebSocket 协议在 macOS 同样生效且无平台特定依赖。
